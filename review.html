Problem type 1 · Computational graph and backprop

The method, every time

  1. Break the expression into single operations. One node per operation, innermost first. Give each intermediate a name (a, b, c…).
  2. Forward pass, left to right. Write each value on its edge.
  3. Backward pass, right to left. Start with 1 at the output. At each node:
    gradient on an input = upstream gradient × local derivative.
  4. Add at branches. If a variable feeds several nodes, its gradient is the sum over all those paths.
  5. Sanity-check with algebra if you have a minute: simplify the function for the active branch and differentiate directly.

Worked example 2 · the Quiz 2 problem

Quiz 2, Exercise 1 \[ y = \text{ReLU}(w_1 x_1 + w_2 x_2 + b), \qquad x_1 = 2,\; x_2 = 1,\; w_1 = 1,\; w_2 = 0.5,\; b = 1 \]

Forward: \(1\cdot 2 = 2\), \(0.5 \cdot 1 = 0.5\), sum \(= 2.5\), plus bias \(= 3.5\), ReLU \(= 3.5\). Backward: ReLU passes 1 because \(3.5 > 0\); both add nodes pass 1 along; each multiply node hands every input the other input.

\[ \frac{\partial y}{\partial w_1} = x_1 = 2 \qquad \frac{\partial y}{\partial w_2} = x_2 = 1 \qquad \frac{\partial y}{\partial b} = 1 \qquad \frac{\partial y}{\partial x_1} = w_1 = 1 \qquad \frac{\partial y}{\partial x_2} = w_2 = 0.5 \]

Worked example 3 · the sigmoid graph from the MLP slides

The slides walk through \(f(x, w) = \dfrac{1}{1 + e^{-(w_0 x_0 + w_1 x_1 + w_2)}}\) with \(w_0 = 2,\; x_0 = -1,\; w_1 = -3,\; x_1 = -2,\; w_2 = -3\), one node at a time. Rework it once with the gradients hidden.

  • \(1/x\) node: local \(= -1/1.37^2 = -0.53\). So \(1.00 \times -0.53 = -0.53\).
  • \(+1\) node: local \(= 1\). Still \(-0.53\).
  • \(\exp\) node: local \(= e^{-1} = 0.37\). So \(-0.53 \times 0.37 = -0.20\).
  • \(\times(-1)\) node: local \(= -1\). So \(+0.20\).
  • Both add nodes pass \(0.20\) to every input, so \(\partial f/\partial w_2 = 0.20\).
  • Multiply nodes swap: \(w_0\) gets \(x_0 \times 0.20 = -0.20\), \(x_0\) gets \(w_0 \times 0.20 = 0.40\), \(w_1\) gets \(x_1 \times 0.20 = -0.40\), \(x_1\) gets \(w_1 \times 0.20 = -0.60\).
Shortcut

The four nodes \(\times(-1)\), exp, \(+1\), \(1/x\) together are just a sigmoid, and \(\sigma' = \sigma(1-\sigma) = 0.73 \times 0.27 \approx 0.20\). One step instead of four. Use the long way only if the question draws the graph that way.

Practice · do these on paper

Practice A · warm-up

\(f(x, y, z) = (x + y)\cdot z\) with \(x = -2,\; y = 5,\; z = -4\). Find all three partial derivatives.

Solution

Forward: \(q = x + y = 3\), \(f = q \cdot z = -12\).

Backward: \(\partial f/\partial q = z = -4\), \(\partial f/\partial z = q = 3\). The add node passes \(-4\) to both inputs.

\(\partial f/\partial x = -4\), \(\partial f/\partial y = -4\), \(\partial f/\partial z = 3\).

Practice B · same shape as the review problem, with max

\(f(x, y) = (x - y)\cdot \max\!\left(\dfrac{x}{y},\; y\right)\) with \(x = 10,\; y = 4\).

Solution

Forward: \(a = x - y = 6\); \(b = x/y = 2.5\); \(c = \max(2.5, 4) = 4\) (y is selected); \(f = a \cdot c = 24\).

Backward: \(\partial f/\partial a = c = 4\); \(\partial f/\partial c = a = 6\). The max sends 6 to \(y\) and 0 to \(b\), so nothing flows through the division.

  • x: through \(a\): \(4 \times 1 = 4\). Through \(b\): 0. Total 4.
  • y: through \(a\): \(4 \times (-1) = -4\). Through max: \(6\). Through \(b\): 0. Total 2.

Check: the active branch is \(f = (x - y)\,y = xy - y^2\), so \(\partial f/\partial x = y = 4\) and \(\partial f/\partial y = x - 2y = 2\).

Practice C · three inputs

\(f(x, y, z) = (x \cdot y + z)\cdot \max(y,\; z)\) with \(x = 3,\; y = -2,\; z = 4\).

Solution

Forward: \(a = xy = -6\); \(b = a + z = -2\); \(c = \max(-2, 4) = 4\) (z is selected); \(f = b \cdot c = -8\).

Backward: \(\partial f/\partial b = c = 4\); \(\partial f/\partial c = b = -2\). The add node passes 4 to both \(a\) and \(z\). The max sends \(-2\) to \(z\) and 0 to \(y\).

  • x: \(4 \times y = 4 \times (-2) =\) −8
  • y: \(4 \times x = 12\), plus 0 through max: 12
  • z: \(4\) through the add, plus \(-2\) through the max: 2
Practice D · a sigmoid neuron with a loss, then one update

\(z = w x + b\), \(a = \sigma(z)\), \(L = (a - y)^2\). Given \(x = 1,\; w = 2,\; b = -2,\; y = 1\). Find \(\partial L/\partial w\) and \(\partial L/\partial b\), then take one gradient-descent step with \(\alpha = 1\).

Solution

Forward: \(z = 2 - 2 = 0\); \(a = \sigma(0) = 0.5\); \(L = (0.5 - 1)^2 = 0.25\).

Backward:

  • \(\partial L/\partial a = 2(a - y) = -1\)
  • \(\partial a/\partial z = a(1 - a) = 0.25\), so \(\partial L/\partial z = -0.25\)
  • \(\partial L/\partial w = -0.25 \times x = \mathbf{-0.25}\) and \(\partial L/\partial b = -0.25 \times 1 = \mathbf{-0.25}\)

Update: \(w \leftarrow 2 - 1(-0.25) = 2.25\), \(b \leftarrow -2 - 1(-0.25) = -1.75\). Both move so that \(z\) grows and the output moves toward the target of 1.

Practice E · ReLU neuron with a squared loss

\(y = \text{ReLU}(w_1 x_1 + w_2 x_2 + b)\), \(L = (y - t)^2\). Given \(x_1 = 1,\; x_2 = 2,\; w_1 = 3,\; w_2 = -1,\; b = 0.5,\; t = 1\). Find the gradients of \(L\) with respect to \(w_1, w_2, b\), and the new weights after one step with \(\alpha = 0.1\).

Solution

Forward: \(z = 3 - 2 + 0.5 = 1.5\); \(y = 1.5\); \(L = 0.5^2 = 0.25\).

Backward: \(\partial L/\partial y = 2(y - t) = 1\). ReLU is open (\(z > 0\)), so \(\partial L/\partial z = 1\).

\(\partial L/\partial w_1 = x_1 = 1\), \(\partial L/\partial w_2 = x_2 = 2\), \(\partial L/\partial b = 1\).

Update: \(w_1 = 3 - 0.1 = 2.9\), \(w_2 = -1 - 0.2 = -1.2\), \(b = 0.5 - 0.1 = 0.4\).

Practice F · what if the ReLU is off?

Same neuron \(y = \text{ReLU}(w_1 x_1 + w_2 x_2 + b)\) with \(x_1 = 1,\; x_2 = 2,\; w_1 = 1,\; w_2 = -2,\; b = 1\). Find \(\partial y/\partial w_1\), \(\partial y/\partial w_2\), \(\partial y/\partial b\).

Solution

\(z = 1 - 4 + 1 = -2\), so \(y = \text{ReLU}(-2) = 0\). The local derivative of ReLU is 0 for a negative input, so the gradient is blocked: all three are 0.

This is the “dying neuron” problem. With zero gradient the weights do not update. Leaky ReLU keeps a small slope for negative inputs to avoid it.

Problem type 2 · Weight-matrix shapes

The rule

A weight matrix connects what comes into a layer to the neurons of that layer. One dimension is the number of inputs to the layer (plus 1 if the bias is folded in). The other is the number of neurons. The convention only decides which comes first. The number of training samples never appears in a weight shape.

ConventionShape of W for a layerBiasUsed in
\(\text{net} = XW\)(inputs + 1) × neuronsFirst row of W. X gets a column of 1s, so X is samples × (inputs + 1).Review sheet, Quiz 2
\(\text{net} = Wx + b\)neurons × inputsSeparate vector with one entry per neuronMLP slides (CIFAR-10), multi-layer handout

The check that catches mistakes: write the multiplication and make sure the inner dimensions agree. \((5 \times 8)(8 \times 9) \rightarrow 5 \times 9\).

Trap: orientation

The Quiz 2 key printed the shapes neurons-first (12 × 7) even though the question said \(\text{net} = XW\), and the grading notes said either orientation was accepted. The review sheet is more specific: “bias is included in the first row”. A bias row has one entry per neuron, so rows = inputs + 1 and columns = neurons, which gives 8 × 9.

What to write: the shape, what the rows and columns mean, and the dimension check. For example: “W₁ is 8 × 9 (8 = 7 inputs + 1 bias row, 9 = neurons). X(5×8)·W₁(8×9) = 5×9.” That is correct under either reading.

Problem type 3 · Softmax and cross-entropy

The method

  1. Softmax turns the raw outputs \(z\) into probabilities: \[ \hat{y}_k = \frac{e^{z_k}}{\sum_j e^{z_j}} \]
  2. Cross-entropy compares them with the target \(y\): \[ L = -\sum_k y_k \,\ln(\hat{y}_k) \]
  3. If the target is one-hot, every term but one is multiplied by 0, so \(L = -\ln(\hat{y}_{\text{true class}})\).
Numbers and a shortcut

\(e \approx 2.718\), \(e^2 \approx 7.389\), \(e^3 \approx 20.09\), \(\ln 2 \approx 0.693\), \(\ln 3 \approx 1.099\).

Without a calculator, use \(\ln \hat{y}_k = z_k - \ln\!\big(\sum_j e^{z_j}\big)\). For two outputs that differ by 1, the probabilities are always \(\tfrac{1}{1+e} = 0.269\) and \(\tfrac{e}{1+e} = 0.731\).

Worked example · the review-sheet problem

Review sheet, Problem 3

The last layer has two nodes and its output is \(\begin{bmatrix}1\\2\end{bmatrix}\). Using softmax, compute the cross-entropy loss with the natural log.

Step 1, softmax. \(e^1 = 2.718\), \(e^2 = 7.389\), sum \(= 10.107\).

\[ \hat{y} = \left[\frac{2.718}{10.107},\; \frac{7.389}{10.107}\right] = [\,0.269,\; 0.731\,] \qquad \ln\hat{y} = [\,-1.313,\; -0.313\,] \]

Step 2, the loss. It depends on the desired output:

Desired outputLossValue
\([0, 1]\) (class 2 is correct)\(-\ln 0.731\)0.313
\([1, 0]\) (class 1 is correct)\(-\ln 0.269\)1.313
\([1, 2]\), exactly as printed on the sheet\(-(1\cdot\ln 0.269 + 2\cdot\ln 0.731) = 1.313 + 0.627\)1.940
Trap: the sheet’s target is not one-hot

The review sheet prints the desired output as \([1, 2]\), the same as the actual output. A real target for softmax is one-hot, so that looks like a placeholder. The method does not change: apply \(L = -\sum y_k \ln \hat{y}_k\) to whatever target the exam prints. If it is one-hot, only one term survives.

Practice

Practice 1

Network outputs \([2, 1, 0]\). The first class is the correct one. Find the softmax probabilities and the loss.

Solution

\(e^2 + e^1 + e^0 = 7.389 + 2.718 + 1 = 11.107\).

\(\hat{y} = [0.665,\; 0.245,\; 0.090]\). \(L = -\ln 0.665 =\) 0.408.

Shortcut: \(\ln \hat{y}_1 = 2 - \ln 11.107 = 2 - 2.408 = -0.408\).

Practice 2

Network outputs \([3, 1]\). The desired output is \([0, 1]\).

Solution

\(e^3 + e^1 = 20.086 + 2.718 = 22.804\). \(\hat{y} = [0.881,\; 0.119]\).

\(L = -\ln 0.119 =\) 2.127. The network was confident and wrong, so the loss is large. If the target had been \([1, 0]\), the loss would be only \(-\ln 0.881 = 0.127\).

Practice 3

A 3-class network outputs \([0, 0, 0]\). What is the loss, whichever class is correct?

Solution

Equal scores give equal probabilities, \(\tfrac13\) each. \(L = -\ln\tfrac13 = \ln 3 =\) 1.099. A network that knows nothing about \(K\) classes has loss \(\ln K\).

Practice 4 · no softmax needed

The predicted probabilities are \(\hat{y} = [0.6,\; 0.3,\; 0.1]\) and the true class is the first. Find the loss. Then find it for a binary classifier that outputs \(\hat{y} = 0.8\) when (a) \(y = 1\) and (b) \(y = 0\).

Solution

These already sum to 1, so do not apply softmax again. \(L = -\ln 0.6 =\) 0.511. This is the example in the single-layer notes.

Binary cross-entropy: \(L = -[\,y\ln\hat{y} + (1-y)\ln(1-\hat{y})\,]\).

  • (a) \(y = 1\): \(-\ln 0.8 =\) 0.223
  • (b) \(y = 0\): \(-\ln 0.2 =\) 1.609
If they ask for the gradient

One gradient-descent step for linear regression

Data from the notes: \((x, y) = (1, 2)\) and \((2, 4)\). Model \(z = wx + b\), start at \(w = 0,\; b = 0\), using the notes’ gradients \(\partial L/\partial w = \sum (z_i - y_i)\,x_i\) and \(\partial L/\partial b = \sum (z_i - y_i)\).

  • Predictions: \(z = 0, 0\). Errors: \(-2,\; -4\). Starting MSE \(= (4 + 16)/2 = 10\).
  • \(\partial L/\partial w = (-2)(1) + (-4)(2) = -10\). \(\partial L/\partial b = -6\).
  • With \(\alpha = 0.5\): \(w = 5,\; b = 3\). New predictions 8 and 13, MSE \(= 58.5\). The loss went up: overshoot.
  • With \(\alpha = 0.1\): \(w = 1,\; b = 0.6\). New predictions 1.6 and 2.6, MSE \(= 1.06\). The loss went down.
The lesson the notes draw

When you overshoot, the direction (the gradient) is fine and the step size is too large. The first thing to fix is the learning rate. Gradient descent has converged when the gradient is approximately 0.

Element-wise versus matrix product

Every arithmetic operator is element-wise, including * and /. The matrix product needs np.dot(a, b).

With a = [[1,2],[9,8]] and b = [[6,5],[2,4]]: a * b = [[6,10],[18,32]] but np.dot(a, b) = [[10,13],[70,77]]. And np.dot of two 2×3 arrays is an error, because the inner dimensions (3 and 2) do not match.

Universal functions (ufuncs) such as np.sin, np.cos, np.exp, np.sqrt operate element-wise on an array and return an array.

Broadcasting

Broadcasting is how NumPy does arithmetic between arrays of different shapes. Two rules:

  1. If the arrays have different numbers of dimensions, prepend 1s to the shape of the smaller one.
  2. An axis of size 1 is stretched (copied) to match the other array along that axis.

Vectorization

Applying an operation to the whole array at once instead of looping. In the notes, np.dot on 10 million elements took about 9 ms and the Python loop about 3.2 s.

Trap: (5,) is not a column vector

np.random.randn(5) has shape (5,). Its transpose is the same thing, and np.dot(a, a.T) is a single number. Use np.random.randn(5, 1) to get a real 5×1 column: then a.T is 1×5, np.dot(a.T, a) is 1×1 and np.dot(a, a.T) is 5×5.

Revision · Single-layer networks

One layer of neurons connected directly to the inputs, feed-forward. They all compute \(z = w^{\top}x + b\) and differ only in the activation and the loss.

ModelActivationOutputLossTrained by
Linear regressionIdentity\(\hat{y} = z\), any real numberMSEGradient descent
PerceptronStep: 1 if \(z \ge 0\)0 or 1none (not differentiable)Perceptron update rule
Logistic regressionSigmoid\(P(y = 1 \mid x)\) in (0, 1)Binary cross-entropyGradient descent

Key formulas

\[ \text{MSE: } L = \frac{1}{m}\sum_i (z_i - y_i)^2 \qquad \text{Binary CE: } L = -\big[\,y\ln\hat{y} + (1-y)\ln(1-\hat{y})\,\big] \qquad \text{CE: } L = -\sum_k y_k \ln\hat{y}_k \] \[ \text{Gradient descent: } w \leftarrow w - \alpha\,\nabla L(w) \qquad \text{Perceptron: } w \leftarrow w + \eta\,(y - \hat{y})\,x,\;\; b \leftarrow b + \eta\,(y - \hat{y}) \]
  • Decision boundary is \(z = 0\): a line for 2 inputs, a plane for 3. The bias shifts it; with no bias it must pass through the origin.
  • Gradients: linear regression uses \((z - y)\,x\); logistic regression uses \((\hat{y} - y)\,x\) with \(\hat{y} = \sigma(z)\). Same form, different prediction.
  • Logistic decision rule: class 1 if \(\hat{y} \ge 0.5\), which is the same as \(z \ge 0\).
  • Perceptron: the step function is not differentiable, so no gradient descent. It converges only if the data is linearly separable. An epoch is one full pass over the training set.
  • Why softmax for multiclass: K separate sigmoids do not sum to 1, which makes no sense when exactly one class is true. Softmax makes the outputs positive, summing to 1, and competing.
  • One-hot encoding: class k of K becomes a vector of 0s with a 1 in position k. Then \(L = -\ln(\hat{y}_{\text{true}})\). It punishes confident wrong predictions heavily.
  • Prediction for multiclass: compute softmax, take the argmax.
  • Chain rule: \(\dfrac{dy}{dx} = \dfrac{df}{dg}\cdot\dfrac{dg}{dx}\). Example: \(y = \sin(x^2) \Rightarrow \cos(x^2)\cdot 2x\).
  • Can solve: linearly separable problems (AND, OR, linear and logistic regression). Cannot solve: XOR.

Revision · Multi-layer networks and activations

Five limitations of a single-layer network

  1. It can only model linear functions (works for AND and OR, fails for XOR).
  2. It cannot capture complex patterns: no curves, clusters or complex boundaries.
  3. Limited feature extraction: no hidden layers, so no intermediate representations.
  4. Limited capacity: few parameters.
  5. Sensitive to noisy data: generalises poorly on noisy or overlapping data.

Hidden layers

A hidden layer is any layer between the input and the output layer. It contains inputs, weights, a bias and an activation function, and performs intermediate computations. Hidden layers matter because they introduce non-linearity, learn hierarchical features, increase expressiveness, enable complex decision boundaries and make deep learning possible.

\[ a^{(l)} = f\big(W^{(l)} a^{(l-1)} + b^{(l)}\big) \qquad \text{stacking layers} = \text{composing functions} \]

Activation functions

FunctionFormulaRangeDerivativeRemember
Sigmoid\(\dfrac{1}{1+e^{-z}}\)(0, 1)\(\sigma(1-\sigma)\), at most 0.25Smooth; vanishing gradients; not zero-centred; slow in deep nets; used in the output layer for binary classification
Tanh\(\dfrac{e^{z}-e^{-z}}{e^{z}+e^{-z}}\)(−1, 1)\(1-\tanh^2\)Zero-centred; better than sigmoid for hidden layers; still has vanishing gradients

Why non-linearity is essential

Without an activation, \(W_2(W_1 x) = (W_2 W_1)x = Wx\). Any stack of linear layers collapses into one linear layer, however deep. The activation is what lets a network learn curves and solve XOR.

Vanishing gradient: backprop multiplies one local derivative per layer. Sigmoid and tanh are flat for large \(|z|\), so those derivatives are close to 0, and after many layers the product is almost nothing. The early layers stop learning. ReLU’s derivative is exactly 1 for positive inputs, so the gradient survives.

From the MLP slides

  • Linear classifier: \(f(x) = Wx\). 2-layer network: \(f(x) = W_2\,\text{act}(W_1 x)\). 3-layer: \(f(x) = W_3\,\text{act}(W_2\,\text{act}(W_1x))\). “2-layer” means two layers of weights.
  • CIFAR-10: \(32\times32\times3 = 3072\) inputs, 10 classes. 2-layer: 3072 → 128 → 10, “learn 128 shared templates instead of 10 separate ones”. 3-layer: 3072 → 512 → 128 → 10.
  • MLP = fully connected network.
  • Traditional vision pipeline: hand-designed features (such as a histogram of gradients), then a linear classifier. Neural networks learn the features automatically, and learn features and classifier end-to-end, using multiple layers.

Revision · Back-propagation theory

  • Training updates each layer with SGD: \(W_k \leftarrow W_k - \alpha\,\dfrac{\partial e}{\partial W_k}\). Backprop is how you get \(\partial e/\partial W_k\) for every layer.
  • It is the chain rule, applied from the output back to the input.
  • For any layer: \(\dfrac{\partial e}{\partial W_k} = \underbrace{\dfrac{\partial e}{\partial h_k}}_{\text{from the higher layer}} \cdot \underbrace{\dfrac{\partial h_k}{\partial W_k}}_{\text{current layer}}\)
  • Each layer does two jobs: compute \(\partial h_k/\partial W_k\) to update its own weights, and compute \(\partial h_k/\partial h_{k-1}\) to pass the gradient down: \(\dfrac{\partial e}{\partial h_{k-1}} = \dfrac{\partial e}{\partial h_k}\cdot\dfrac{\partial h_k}{\partial h_{k-1}}\).
  • If a layer’s output feeds two places, the incoming gradients are added.
Case on the slidesResult with L2 loss \(e = (y - h)^2\)
1 layer, \(h_1 = W_1 x\)\(\dfrac{\partial e}{\partial W_1} = -2\,(y - h_1)\,x\)
2 layers, \(h_2 = W_2 h_1\)\(\dfrac{\partial e}{\partial W_2} = -2\,(y - h_2)\,h_1\)  and  \(\dfrac{\partial e}{\partial W_1} = -2\,(y - h_2)\,W_2\,x\)
1 layer + sigmoid, \(h_2 = \sigma(h_1)\)\(\dfrac{\partial e}{\partial W_1} = -2\,(y - h_2)\;\sigma(h_1)\,(1 - \sigma(h_1))\;x\)

The slides end with “derive the 2-layer case yourself”. The middle row is that derivation: \(\partial e/\partial h_2 = -2(y - h_2)\), \(\partial h_2/\partial h_1 = W_2\), \(\partial h_1/\partial W_1 = x\), and you multiply the three.

Asked on Quiz 1

Supervised vs unsupervised learning, by the data they use

Supervised learning uses labeled data: input features and an output label, and the model learns the relationship so it can predict outputs for new data (house prices, medical imaging). Unsupervised learning uses unlabeled data: features only, and the algorithm discovers hidden patterns or groupings (customer segmentation, market-basket analysis).

Why does data matter in machine learning?

Data is the first of the four key components. The model learns from data instead of being explicitly programmed, each observation is a set of feature values in which the model finds relationships, and the quality and nature of the data determine what the model can do.

Purpose of activation functions, and what happens without them

An activation function is applied to a neuron’s weighted sum and introduces non-linearity, which lets the network learn complex patterns and curved boundaries. It also shapes the output (sigmoid gives a probability). Without it the whole network collapses to a single linear model, however many layers it has.

What problems can a single-layer network solve?

Linearly separable problems, where one straight line (or plane) separates the classes, and linear input-output relationships. Examples: linear regression, logistic regression, AND and OR with a perceptron.

Main limitation of a single-layer perceptron

It can only produce a linear decision boundary, so it only works on linearly separable data. It handles AND and OR but fails on XOR. Supporting points: no hidden layers, the step function is not differentiable, and limited capacity.

Single-layer vs multi-layer network

A multi-layer network has one or more hidden layers with non-linear activations between input and output. That lets it learn non-linear decision boundaries and hierarchical features, and solve XOR. A single-layer network goes straight from input to output and is limited to linear boundaries.

Why choose the right measurement scale?

The scale determines which properties the values have (identity, order, equal intervals, true zero) and therefore which operations and statistics are valid. With the wrong scale you do meaningless arithmetic, such as saying 40 °C is twice as hot as 20 °C.

Which scale for height, weight and age, and why?

The ratio scale. These satisfy all four properties, including a true zero, so ratios, multiplication and division are meaningful (20 kg is twice 10 kg).

Why are NumPy arrays faster than Python lists?

Vectorization: operations are applied to the whole array at once by built-in universal functions instead of element by element in a Python loop. This works because all elements have the same type, so the data is stored and processed uniformly.

Likely new ones

Why can’t the perceptron be trained with gradient descent?

Its step activation is not differentiable, so there is no gradient to follow. It uses the perceptron update rule \(w \leftarrow w + \eta(y - \hat{y})x\) instead, which only changes the weights on a mistake.

Why softmax and not sigmoid for multi-class classification?

Separate sigmoids give independent outputs that do not sum to 1, which makes no sense when exactly one class is true. Softmax gives positive outputs that sum to 1, so they are a valid probability distribution over the classes.

What is the vanishing gradient problem and how does ReLU help?

During backprop the gradient is a product of local derivatives. Sigmoid and tanh saturate, so their derivatives are near 0 for large inputs, and the gradient shrinks toward zero in the early layers, which stop learning. ReLU’s derivative is 1 for positive inputs, so the gradient passes through undiminished.

What is a dying ReLU and how does Leaky ReLU fix it?

If a ReLU neuron’s input stays negative, its output and its gradient are both 0, so its weights never update again. Leaky ReLU keeps a small non-zero slope for negative inputs, so some gradient always flows.

What is back-propagation?

The algorithm that computes the gradient of the loss with respect to every weight by applying the chain rule from the output layer back to the input. Each layer multiplies the gradient from the higher layer by its own local gradient. Gradient descent then uses those gradients to update the weights.

What does the bias do?

It is a constant added to the weighted sum that shifts the decision boundary (shifts the activation). Without it the boundary must pass through the origin.

What does the learning rate control? Too large? Too small?

The step size of each weight update. Too large: the update overshoots the minimum and the loss can increase. Too small: training is very slow.

What is a hidden layer and why is it important?

Any layer between the input and output layers. It transforms the input into intermediate representations, and with a non-linear activation it lets the network learn hierarchical features and complex decision boundaries.

What is a convolution in a CNN?

Sliding a small filter of learnable weights over the input and taking a local dot product at each position. The result is an activation map that is large wherever the filter’s pattern appears.

Why use a CNN instead of an MLP for images?

A filter is small and shared across all positions, so a CNN needs far fewer parameters, keeps the spatial structure of the image, and detects a feature wherever it appears. It also learns its own features instead of relying on hand-crafted ones.

What is pooling and why is it used?

A fixed operation (max or average) applied over small regions of each activation map, with no learnable weights. It reduces the spatial size and gives slight translation invariance, so the exact position of a feature is not critical.

What is deep learning, and what are its challenges?

A modern evolution of neural networks that emphasises very deep networks, large unstructured datasets and modern compute (GPUs). Challenges: vanishing gradients (use BatchNorm, skip connections), overfitting (regularization, data augmentation) and needing a lot of data (transfer learning).
